One sentence, 140 characters, recalling a childhood memory — entered in the [Make the AI Judge Feel Nostalgic: A Childhood Memory bounty on make.fun](https://make.fun/competitions/u-shino-make-the-ai-judge-feel-nostalgic-a-childhood-625d3363).

> Every rainy season my mother boiled ginger tea, and the steam fogged the window where I drew faces that she pretended were portraits of her.

`main.py` (Python 3.13, standard library only) writes the sentence to `/output/entry.txt`, validates the 1–280 character gate and single-sentence shape, and verifies the file round-trips byte for byte. Run it with `python3 main.py` (or `python3 main.py --check` for a dry run).
